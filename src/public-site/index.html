A few things to know.

Does Canon replace my coding agent?

No. Your agent still builds the application. Canon gives it project design context, tools and supported style checks.

Does it replace shadcn/ui?

No. In library mode, Canon reads and edits the installed library. The current adapter supports shadcn/ui. Support for more libraries is planned; those adapters are not available yet. Canon does not install the entire upstream catalog or replace your components with a second visual copy.

What does --save-dev mean?

It adds Canon to devDependencies. Canon runs during development. Your deployed application uses its own saved component source and theme CSS.

Does it guarantee that an agent follows the design?

No. Instructions guide the agent, and checks detect supported violations. They are not a security boundary or a substitute for application tests, accessibility checks and visual review.
